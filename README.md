# Agentio — pilots

1 working pilot built for Agentio.

### Attribution truth harness

414 conversions with a known cause for each: 161 were caused by the creator placement, and last click reports 7 of them \u2014 because 92% of placements are watched without a click and 62% happen before the 7-day window opens.

`companies/agentio/agentio-attribution-truth/`

## Running it

```bash
npm install
npm run dev
```

## Note on the data

Every figure in these pilots is synthetic and labelled as such in the interface.
Nothing here is connected to Agentio's systems, and no number should be
read as a measurement of their business.
